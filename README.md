# 说明
## 功能及特色
+ 支持拖放操作载入图像文件。
+ 删除图像背景和更换图像背景。
+ 更换的背景可以是纯色，也可以是另一张图像。当指定另一张图像为背景时，可以产生两张图像融合的效果。
+ 扩展QGraphicsView类作为图像容器，实现了以鼠标为锚缩放图像的功能。
+ 可以通过指定颜色范围（RGB分量及灰度中的一个或几个）定义要删除的背景范围，也可以通过矩形或多边形标记来指定背景范围。
+ 可以通过矩形或多边形标记前景范围对前景加以保护，避免与背景颜色相近的前景色被破坏。
## 操作方法
1. 通过点击**载入图像**按钮或**拖放图像进入图像操作区**可载入图像。
2. 点击**选取前景**或**选取背景**按钮进入前景或背景*区域选取模式*。选取的前景区域不会被删除，选取的背景区域总是会被删除。重新选取前景或背景时会清除此前已标记的前景或背景区域。进入*区域选取模式*会禁用程序右边的操作按钮和文本框等控件，点击鼠标右键可退出*区域选取模式*并激活操作控件。
3. *区域选取模式*下**点击一次鼠标左键**可以指定多边形的一个顶点，点击鼠标右键完成多边形绘制；*按住Ctrl键并按住鼠标左键拖拽*可以画矩形。
4. 点击**查看图像颜色**按钮，将鼠标在图像上移动可查看鼠标位置像素点的颜色信息，以供指定背景颜色范围时参考。在*颜色信息查看模式*下会禁用程序右边的操作按钮和文本框等控件，**鼠标点击图像操作区**可退出*颜色信息查看模式*并激活操作控件。
5. 点击**原始图像**按钮，可以在*图像操作区*显示原始图像并重新处理。依次点击处理结果按钮和原始图像按钮，可以对比观察处理效果。
6. 选取背景后按下delete键可以删除选中的背景。按下R键可以撤销所有操作。
